# ORBIT LAUNCHER

`Orbit-Launcher.exe`를 실행하세요. Windows 기본 .NET Framework를 사용하는 독립 GUI 런처입니다.

- 궤도 공방 실행 파일을 자동으로 찾거나 **게임 위치 선택**으로 지정합니다.
- 선택한 경로는 다음 실행에도 유지됩니다.
- **다운로드**는 궤도 공방의 GitHub Releases를 엽니다.
- **모드 파일 열기**는 일베크래프트 파일 폴더 또는 저장소를 엽니다.
- **Minecraft mods**는 기본 `%APPDATA%\.minecraft\mods` 폴더를 엽니다. 다른 런처는 해당 인스턴스 폴더를 사용하세요.

게임 본체는 별도로 필요합니다. 런처는 자동으로 모드를 덮어쓰거나 게임을 설치하지 않습니다.
`Launcher.cs`에 소스를 함께 제공했습니다.
